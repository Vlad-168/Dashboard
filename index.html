A home screen widget with today’s training and lessons, your next tournament, streak and GitHub tasks. Small, medium and large sizes; tap it to open the dashboard.

  1. Install the free Scriptable app.
  2. Tap Copy widget script below.
  3. In Scriptable tap +, paste, and name it Dashboard.
  4. Run it once (▶︎) and paste your GitHub token — it’s saved in the iOS Keychain.
  5. Long‑press the home screen → + → Scriptable → pick a size → tap the widget → Script: Dashboard.

Refresh: iOS decides when widgets update. The widget asks to refresh right after midnight, after each session and every 15 minutes; “↻ 5 min” shows how fresh it is. Keep Background App Refresh on for Scriptable (Settings → General) — in Low Power Mode iOS pauses widget updates. After updating the script, paste the new version into Scriptable.

The widget reads the same private sync as this dashboard.
